会未经确认直接发布吗？

不会。保存 eBay 未发布草稿与正式发布是不同操作；店铺授权、套餐权限、资料和发布前检查满足要求后，由你在确认中心确认，再通过 eBay API 正式发布。账号受限或资料缺失时会提示原因，最终结果以 eBay 返回为准。

免费体验会自动扣费吗？

不会。免费体验不绑卡、不自动续费；需要付费时会再次显示方案和金额。
