# 捷境 Runtime 长期记忆与创意引擎推进记录

日期：2026-05-15

本文档记录本轮对捷境自研 Agent Runtime 的两个关键补强：

1. 长期记忆系统
2. 设计、图片、视频创意能力合同

---

## 1. 为什么要做长期记忆

静态知识包解决的是：捷境应该遵守哪些规则、SOP、报告模板和确认边界。

长期记忆解决的是：系统跑过任务以后，能不能记住这个商家、店铺、商品、流程和岗位的可复用经验。

长期记忆不是：

- 不是密钥库。
- 不是买家隐私库。
- 不是自动执行权限。
- 不是把 Hermes 文件原样塞进系统。

长期记忆只保存脱敏后的：

- 商家偏好
- 店铺规则
- 商品经验
- 市场判断结论
- 刊登字段缺口
- 素材要求
- 客服边界
- 财务复核经验
- 确认中心规则

---

## 2. 已落地工程

新增：

- `jiejing_runtime/long_term_memory.py`
- SQLite 表：`long_term_memories`
- API：
  - `GET /memories`
  - `GET /memories/summary`
  - `POST /memories`

Runtime 每次导入一条运行记录时，会从结果中抽取安全记忆候选。

例如：

- 市场报告会沉淀商品测试判断、价格带、风险方向。
- 产品刊登会沉淀 eBay 字段、Item Specifics、待补资料。
- 素材工坊会沉淀主图、场景图、详情页、视频脚本要求。
- 客服学习会沉淀售前售后话术边界。
- 财务复核会沉淀利润、物流和停止条件。
- 确认中心会沉淀哪些动作必须确认。

---

## 3. 记忆安全边界

长期记忆系统会拒绝或脱敏：

- access token
- refresh token
- authorization / cookie
- password / secret
- 买家邮箱
- 买家地址
- 银行卡或支付敏感信息

长期记忆不授予真实执行权。

真实发布、采购付款、退款、广告预算和政策修改仍然必须进入确认中心和后端执行服务。

---

## 4. 创意引擎的正确理解

捷境可以拥有类似 Claude Design / Open Design 那类优秀设计工作流的能力，但不能复制任何闭源产品的内部实现。

我们的正确做法是：

- 学习优秀设计工作流的思想。
- 沉淀捷境自己的电商创意流程。
- 把图片、详情页、视频、口播、封面统一成资产任务和资产清单。
- 接不同图片/视频/语音模型作为 provider。
- 所有生成文件必须回写 asset manifest。

---

## 5. 已落地创意能力合同

新增：

- `jiejing_runtime/creative_capabilities.py`
- API：
  - `GET /creative-capabilities`

已定义能力：

- Open Design 风格探索
- Listing 素材任务包
- 产品主图生成
- 详情页长图生成
- 产品视频生成
- 口播脚本和配音

当前状态：

- 设计方法和素材任务包已经属于捷境 Runtime。
- 真实图片/视频/配音生成还需要配置外部 provider。
- provider 接入后必须返回 asset manifest，不能只说“已生成”。

## 6. 下一步

下一步不是继续堆页面，而是补真实工具：

1. 接真实模型客户端，让 7 个 Agent 不再只是规则版。
2. 接公共搜索 / eBay 只读 / 1688 只读 / 橙联估价工具。
3. 接图片生成 provider。
4. 接视频生成 provider。
5. 接语音/口播 provider。
6. 把每次生成的图片、视频、脚本都写入 asset manifest。
7. 让长期记忆参与下一次任务检索。

---

## 7. 当前结论

捷境自研 Runtime 已经从“任务骨架”推进到“可沉淀记忆、可定义创意能力合同”的阶段。

它还不是完全成熟的 Hermes 替代品，但它正在把捷境最核心的资产拿回来：

- 任务协议
- 岗位规则
- 长期记忆
- 创意合同
- 确认中心
- 执行边界
