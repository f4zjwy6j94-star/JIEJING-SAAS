## 新片的强制质检问题

- 开场：不看说明也知道在解决谁的什么问题吗？前两秒是否有可理解的动作或结果，而不是栏目头？
- 中段：每镜至少贡献一个新信息/动作；全片有没有从商品/资料→处理→结果的因果线，而不是卡片堆叠？
- 视觉：景别与构图是否有变化，主体是否突出？同一张图移动不能冒充交互；“高级感”不等于暗色/金色/大字。
- 口播：在正常速度完整听过吗？自然断句、衔接、语义、字幕及音乐是否一致？测响度/ASR不是真人试听。
- 结束：开头提出的问题解决了吗？官网自然出现且可读吗？只有一个明确下一步吗？当前服务异常时不得诱导即时付费。
- 事实与权利：是不是正在承诺没有证明的自动识别、自动发布、收益、客户效果或零风险？参考片只学习方法，不复制镜头素材、音乐、声音或客户证言。
- 身份标识：画面不加被否决的制作说明页脚；仍保留平台要求的AI声明，不把生成情境说成真人实拍。
- 发布：实际账号/新文件SHA/完整视听/技术/权利门槛/授权/防重复回执分别核对；计划、样片、ready和平台已发布不能混称。

## 每次复盘必须落地一条改动

制作记录追加以下字段，可写在当次制作说明中，不另造第二套总状态：

```text
观察：作品ID、片龄、时间窗、实际指标/缺测、证据入口。
假设：待检验的解释；其他可能原因及小样本限制。
学习来源：具体作者/作品/时间段，实读范围；不写“看过全网”。
本次修改：原镜头/句子 → 新镜头/句子；解决什么问题。
主动采用：技能及实际输出；未用什么、为什么。
验证：主画面、带声样段、完整视听与技术结果分开。
结果：待审/被拒/已批准/已提交/公开状态，不把未来目标写成完成。
下次动作：一个可验证改动；多项重构不称单变量实验。
```
