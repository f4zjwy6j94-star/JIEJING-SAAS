启动说明保存在私人环境配置草稿；草稿保存不等于发布。仓库外资料/输出要依赖已发布的相应快照或另有可验证的私人保存回执，不能只凭当前目录存在承诺未来任务一定取得。新任务必须实际执行上述校验，失败就明确报告。
