## 2. 目标、人群与栏目方向

主目标：让有实际跨境电商需求的人理解捷境、产生有效咨询和体验意向；播放量不是唯一目标。优先面向中文eBay卖家、小团队和有真实货源准备开展跨境业务的经营者，不主打“无货源躺赚”人群。

定位：**用真实案例讲清AI怎样辅助跨境电商运营**。先让观众获得一个具体方法，再用捷境展示承接这个方法的工作流。不是泛AI新闻号，也不是只有品牌介绍的广告合集。AI兴趣是内容入口，跨境经营需求是筛选目标客户的条件；更宽的话题不等于更高的成交价值。

原方案比较过的路线保留：

1. **问题短片 + 对应操作演示（推荐）**：每日形成一个问题/证据组合，兼顾新观众理解和产品信任；需要每条审查真实能力与演示素材。
2. **连续功能课程**：按页面/模块逐集讲解，结构系统，适合已经对产品有兴趣的人；可作为后续收藏型栏目。
3. **创始人实拍日志**：用真实经营和开发故事建立人格信任；需要经营者出镜或提供实拍素材，不能用虚构人物/成交故事替代。

本计划采用路线1，功能课程作为其演示半边。暂不要求真人出镜，不制作“AI生成的用户证言”，不把软件团队制作的宣传视频说成SaaS一键自动生成的真实客户结果。

- 12:00《AI电商实用课》：一个经营问题、一种方法，约25–40秒；目标是让相关新观众愿意继续看、收藏或提出具体问题。
- 20:00《AI电商工作流实操》：同一问题的独立可理解演示，约35–55秒；目标是用真实过程建立信任并产生体验意向，不要求先看过中午视频。
