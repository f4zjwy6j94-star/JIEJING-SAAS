# 项目入口、记忆与双端接续：官方能力核查

2026-10-08。经营者询问能否将原本地10.0和云端11.0放进一个“项目”，降低遗漏并兼顾本机/云端工作。本次只研究和验收已有源码/进度接续；没有移动对话、新建项目、连接设备或改变权限，视频暂停保持。

## 已核实的官方说明

- [Projects and chats](https://learn.chatgpt.com/docs/projects)：桌面“项目”同时包含 ChatGPT 项目与关联电脑文件夹的本地项目。ChatGPT 项目可共用文件、指令、来源；同目录工作不代表所有聊天全文自动汇入一个上下文。同步聊天不上传整个本地文件夹。现有任务仍保留原本地/云端模式。当前账户是否能把这两个既有 Codex 对话放进同一项目尚未实测。
- [Memories](https://learn.chatgpt.com/docs/customization/memories)：ChatGPT 与本地 Codex 使用不同记忆存储；本地记忆后台生成，可能延迟或跳过，不能作为必需规则的唯一依据。官方建议规则保存在 AGENTS.md 或版本化文档。因此项目/记忆不取代已建立的工作记录。
- [Work Cloud local access](https://learn.chatgpt.com/docs/enterprise/cloud-local-access)：符合条件的新 Work Cloud 任务可以使用在线电脑；下一轮电脑不可用时可在云容器继续，但不能读离线文件/工具或在一轮中途迁移。功能取决于账号/工作区及开放范围；不原地转换旧 Codex 对话。
- [Dot 的电脑连接](https://learn.chatgpt.com/docs/dots/computers-and-apps)及[任务与记忆](https://learn.chatgpt.com/docs/dots/tasks-and-memory)：一个 dot 可作为持续沟通入口，在获准且在线的电脑上继续既有本地 Codex 任务，也能在已配置的 Codex 云环境中创建云端代码任务；电脑关闭时其云端仍可用。连接电脑不是读取所有既有聊天的授权，子任务不自动获得全部对话，切换电脑不迁移既有任务。其记忆笔记也不是完整聊天副本。
- [Codex environments](https://learn.chatgpt.com/docs/environments/modes)：现有 Codex Cloud 任务使用独立工作文件，电脑文件、登录态和进程不自动转入。工作目录变化也不更新未来任务的环境起点。

以上官方 Markdown 页面本轮实际 HTTP 200 读取；本轮没有用文档能力冒充当前账号实测。普通 Help Center 的项目文章读取返回403，未据其内容作结论。

## 适合本项目的判断

项目可整理入口，但不能单凭归组宣称现有10.0/11.0已经合并记忆或自动路由。经营者此前截图已有 Your dot，可优先检查其 Computers 页面，验证是否能以一个入口协调两端；这是待验候选，不是已启用方案。既有11.0云端对话能否被它直接接管尚无实证；官方明确支持的是创建云端任务，不能偷换为已接管原11.0。

现有原对话、资料、代码和共享分支先保留。每次重要决定写入唯一执行索引，保留明确原意/必要出处；按任务开工接收、推进保存及远端读回降低偏离。涉及争议时检索已可访问的历史原文；缺少记录就指出缺项，不拿猜测补全。任何入口都不能承诺零遗漏。
