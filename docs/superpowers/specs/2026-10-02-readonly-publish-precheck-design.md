# 发布前只读资料检查

## 目标与范围

本轮目标是原商品的发布前链路验收，不是实际 eBay 刊登。现有系统检查绑定确认单创建，模拟资料被提前拒绝，导致无法查看后端检查结果。采用最小推荐方案：在原第 4 步资料表提供“系统检查资料”；不增加工作流步骤，不调整权限、收费或执行策略。用户已要求自主完成发布前功能；异步选择尚未回复，按默认推荐方案继续低风险实现，不将此记作新的外部执行授权。

## 设计

- 新增已登录、公司/店铺隔离的 `POST /stores/{id}/publish-precheck`。共用现有发布包清洗、服务器来源/图片授权解析、账号快照、执行前检查及发布检查函数。
- 返回字段缺口和只读检查结果；资料来源失败也继续检查其他字段，但不能把无来源数据判为可发布。客户端和服务器已有模拟标记均保留阻断。
- 检查不创建任务、确认单、执行记录，不加载凭据、不访问 eBay 或模型、不修改资料。正常认证自身的会话维护不属于商品执行。
- 返回结果始终标明只读、未获发布授权、没有平台写入。正式确认/执行必须重新运行原完整校验；只读结果没有任何执行权限。
- 前端结果与账户、店铺、项目及当前表单绑定，仅内存保存。编辑或切换项目后失效；网络失败不显示旧通过状态。不污染已有确认单及回执缓存。
- 使用现有页面样式，显示中文分组、通过/待核对/阻断与修复原因，折叠明细。不改官网、导航、套餐或视觉方向。

## 验收

1. 本地真实 HTTP：模拟资料能够返回检查结果、真实确认入口仍拒绝；验证任务/确认/执行数量不增加，跨租户不可读取。
2. 来源/权利缺失、非有限数值、亏损、混合币种保留阻断；合法历史标量售价兼容。
3. 前端测试：成功、失败、并发重复、请求期间编辑/换项目、刷新不复用旧结果；可点击入口真实渲染。
4. 完整部署门禁及同包预演后部署；原 588c 商品从真实 SaaS 点击只读检查，保留模拟与账号限制，不再生成素材、不写 eBay。

## 明确边界

检查依据是已有来源与账号记录，不声称实时验证了 eBay 类目、政策、仓库或图片可达性。正式 eBay 接收成功仍未验收。缺少真实商品参数或账号资格属于外部边界，不得绕过。

## 实施顺序与自审

先修共享数值/费用校验及回归；再补只读 HTTP 与无副作用测试；接前端并验证失效范围；最后完整门禁、部署、原网页验收。已自审：无未定字段、无权限扩张、无平行发布实现。
