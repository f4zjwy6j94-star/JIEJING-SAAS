# 商家素材点使用明细

## 范围与决定

用户已批准按既定顺序自主推进素材点使用明细及失败返还核对，不重复逐步确认。此次补齐已有套餐页的缺口，不改定价、导航、配色、实际扣点算法、测试额度、支付/退款/eBay开关，不部署未获本批明确部署批准的代码。

三个方案：直接公开流水会泄露内部测试与提供商信息，拒绝；另建账本会造成双重真相，拒绝；采用现有账本的后端白名单投影。保持现有余额contract，增加独立usage子contract。

## 行为

- 现有套餐与付款中增加默认折叠的使用明细；只显示当前公司的图片任务。
- 仅现有已认证素材点明细接口显式加载usage；普通余额/配额计算不加载历史，避免同页重复查询。
- 显示当前商家点数暂时占用，以及最近记录的预计点数、最终消耗、已解除占用。解除占用不等同现金退款，也不保证到期或撤销点数恢复可用。
- 最近记录按更新时间排序，最多30条（接口上限100）；扫描最近100条图片预留。截断或旧记录证据不足明确说明，不称全部历史或累计消费。
- 用预留与对应终结流水计算一个任务尝试的一条结果，重复回调不重复记账。预留仍在但终结不匹配显示待核对，不能凭任务失败状态声称已返还。
- 只允许plan_included、purchased、legacy（当前已有普通商家历史额度分类）来源；内部受控验收/owner测试不进入商家余额或明细。混合或缺失来源不输出敏感信息。
- 关联素材任务仅使用同公司数据库记录；不返回原始ledger、bucket、提供商、错误详情、提示词、密钥或用户身份字段。
- 旧后端/网络失败显示明细暂未获取，不显示虚构0条。明确空结果才显示没有可核对的商家点数图片记录。

## 验收

本地真实账本覆盖预留、部分成功、失败释放、重复结算、到期释放、未知/内部来源、租户隔离、截断及异常证据；HTTP接口认证与隔离；真实渲染展开/收起、空/失败/部分覆盖、注入转义、1440/820无溢出。全部为隔离合成数据，不调用模型、生图或真实支付。
