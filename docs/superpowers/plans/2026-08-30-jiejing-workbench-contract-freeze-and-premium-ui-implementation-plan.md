# 捷境工作台业务合同冻结与高端 UI 收敛实施计划

日期：2026-08-30  
关联规格：`docs/superpowers/specs/2026-08-30-jiejing-workbench-contract-freeze-and-premium-ui-design.md`

## 阶段 1：冻结合同

- 补充六项导航、旧记录路由归一和前端资源版本一致性测试。
- 运行 AI CEO、商品身份、Listing、素材、确认、支付退款和 eBay 受控写入专项回归。
- 把旧素材 UI 测试从废弃状态表达式迁移到当前 capability 合同。

## 阶段 2：工作台壳层

- 统一侧栏、顶栏、内容宽度、页面间距、按钮、输入、焦点和状态色。
- 删除可触达的独立记录入口，保留后端留痕与业务页关联。
- 固定桌面、平板、手机布局合同。

## 阶段 3：核心业务页面

- AI CEO：对话优先、简洁首次入口、紧凑交接条、稳定输入区。
- 选品与上架：当前商品、阶段轨道、主要阻断、唯一下一步和渐进展开。
- 素材工坊：当前任务、素材点、生成、审核和 Listing 回写分层。
- 确认中心：只保留高风险动作与三种商家决策。
- 客服与订单：真实消息、建议、修改、发送和高风险交接分层。
- 设置：总览与五类子页聚焦，隐藏内部术语。

## 阶段 4：质量收敛

- 修复商家文案、图片尺寸、表单 name/label、焦点、锚点和 reduced-motion。
- 执行 Open Design critique、产品主理人、新手商家、UI、Reality Checker 复核。
- 修复直接可证的问题，不扩大业务范围。

## 阶段 5：验证与发布准备

- 运行浏览器式桌面、平板、手机回归。
- 运行 Secret 扫描、语法检查、专项测试和完整门禁。
- 运行生产 dry-run 并核对 release manifest。
- 向用户报告网站在线、私测、公开收费、真实平台写入四种状态并请求部署确认。

## 阶段 6：确认后的原子部署

- 以完整 release 同时发布首页、工作台 HTML、JS 和 CSS。
- 绕过缓存核验资源版本一致性。
- 核验 health、deep health、readiness、ops 域和 `app/ops.html=404`。
- 不触发 eBay OAuth、真实收费退款或真实平台写入。
