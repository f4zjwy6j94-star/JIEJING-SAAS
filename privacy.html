JIEJING / 捷境

隐私与数据边界说明

捷境是面向 eBay 商家的 AI CEO 经营工作台。当前环境用于受控 beta 和上线前演练，不是正式公开收费上线状态。

捷境只在商家授权和后端权限边界内处理经营数据。发布、改价、库存、退款、广告、采购付款、政策修改和敏感客服承诺不会由前端或 AI 直接执行，必须进入确认中心、预检和审计流程。

我们处理哪些数据

账号、公司、店铺、授权连接状态、官方 eBay 数据包、报告、确认单、任务记录、审计记录、订阅状态和用量配额会按租户隔离保存。未登录访问不会创建长期经营记忆。

eBay 授权和密钥

eBay OAuth token、refresh token、模型 key、支付 provider secret、client secret 和 API key 只能留在后端密钥/Vault 边界，并以 secret_ref 形式参与审计。浏览器、报告、普通运行时和前端状态不接收原始密钥。

数据来源标记

AI CEO 输出会标记来源：官方 eBay packet、商家上传资料、公开网页、商家规则或模型推理。缺失资料保持待确认，不用猜测冒充事实。

安全和反爬边界

公网会使用 noindex、基础 WAF/Bot 控制、高成本 API 限流、源站访问控制和安全响应头降低抓取和攻击风险。这些措施提高复制和滥用成本，但不能承诺完全阻止所有竞争对手观察公开页面。
