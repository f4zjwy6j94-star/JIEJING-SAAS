## 2. 要学的机制与需要验证的假设

目标观众是已有eBay店铺的中国卖家。品牌是跨境电商AI CEO SaaS，当前支持eBay；第一条讲一个经营任务，后续系列再展开经营协助范围。

| 观众的连续判断 | 视频要做到的事 | 需要观察的证据 |
|---|---|---|
| 这和我有关吗？ | 首帧出现卖家熟悉的材料、字段或待办；开口就进入具体问题 | 前2秒/5秒留存、实际受众、评论是否来自目标卖家 |
| 再看几秒有什么收获？ | 提出一个明确问题，迅速展示处理中的变化 | 分段流失位置、观众能否复述演示任务 |
| 我看懂它怎么做了吗？ | 输入→一次动作→反馈→结果连贯，关键内容在手机上可读 | 是否理解点击前后变化，是否能辨认示意与真实操作 |
| 我凭什么相信？ | 给出能核对的实际输出，未知事实保留未知，承诺在片内兑现 | 与当前产品和原资料一致的证据；没有虚构数据 |
| 值得进一步了解吗？ | 说清适合谁，只安排一个自然入口 | 主页访问、合格咨询、注册和首任务完成 |

这些是创作和验证框架，不是已证实的抖音推荐权重公式。不存在本稿可保证的“几秒多少完播必爆”。情绪来自真实卡点和看懂后的轻松感；不制造订单损失、客户冲突或收益故事。画面在信息发生变化时切换，不为了所谓算法机械每秒闪一次。

开头许诺的答案要在中段交付。比如提出“参数缺了一项”，就让观众看到哪一项、资料从哪里来、怎样处理；不能拖到结尾只说“私信我”。中段让进展可见，结尾让下一步简单。

## 6. 自然、真实、交互清晰的制作要求

以真实软件操作和已获准材料建立可信度，原创动画负责把资料关系讲清楚。首片不依赖合成人物出镜。正常光影、节制运动、口语短句和合理停顿服务内容；不堆科技粒子、虚拟手指或夸张的播报腔。

每个操作片段能回答：点哪里，发生了什么，得到什么。光标、按钮、响应状态按实际次序出现，不用跳剪伪造结果。真实操作占比随解释需要决定，旧15%–20%只是建议；完整动作需要更久时优先保证理解。

每帧只强调一个信息层：主字幕与口播对应，界面只留必要区域，背景动效降低。关键字段给够阅读时间，避免全网页缩成手机小字；检查抖音界面覆盖区域，不以设计稿外观代替手机观看验证。静音能懂，有声不互相抢戏。

历史44张图片只是已审迁移资料，尚未逐项批准用于新广告。首条只需要一组用途获准且事实完整的示例商品资料；沿映射查询已有材料，届时只指出确切缺项，不要求重传全部。硅胶/PVC冲突不能被旁白或生成画面悄悄抹平。

旁白稿可由助手完成；自然中文音源与使用权尚未验证。后续进入制作时先试听短段，再决定是否满足要求。音乐和音效只用明确可用来源，保留无BGM版。AI感低是质检目标，不是承诺所有人都无法察觉生成内容；需要使用的AI标识按当时实际平台要求保留。

## 7. 把观看转成经营结果

内容先吸引已有店铺的卖家，主页承接同一定位和演示任务；之后通过当时账号实际允许的入口主动了解/咨询，进入注册与首任务。挂链、认证和登录均未验收，不把广告片中的CTA画成已获准的官网组件。

内容留存与客户留存分别处理：视频让人持续看懂价值；客户进入后能否完成一个有用任务、得到支持、愿意再次使用，要看真实使用结果。单靠剪辑不能保证留住付费客户。当前只规划这个链路，不修改网站或接入埋点。

| 观察 | 可以提出的下一步检查 | 不应直接得出的结论 |
|---|---|---|
| 开头就流失 | 首帧是否可读、是否说到目标卖家的任务；开口承诺是否清楚 | 账号已被限流 |
| 开头留下，中段掉得快 | 等待过长、文字过密、演示没兑现、吸引来非目标人群等可能性 | 必须每秒多加转场 |
| 看完但很少进一步了解 | 价值是否具体、定位和CTA是否匹配 | 单纯加大“关注私信”音量就会转化 |
| 咨询多但首任务少 | 预期、适用资格、注册和首任务阻碍分别核对 | 播放量就是获客成果 |
| 有首任务但少人回来 | 实际收益、使用频率、支持和后续任务是否成立 | 用更多广告即可解决留存 |

获准发布后记录24/72小时和后续7天观察，带分子/分母、样本量与时间点；平台不提供的指标写未知。先比较相近条件的开头表达，每次只改一个主要变量，但自然分发不是随机实验，保留受众/时段/投流未知等限制。不同版本先私下比较，选择后再发布，不默认批量发近重复作品。

经营指标依次记录：合格卖家咨询、注册、首个有效任务、付费、再次使用和支持反馈。本人自愿提供的信息最小化记录，不收集无关个人资料。先自然内容学习，预算/投流/群发均未授权。
