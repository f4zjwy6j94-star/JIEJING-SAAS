## 共用创意与交付规则

目标人群是有经营任务的跨境卖家，不是泛AI猎奇观众。中午给方法，晚上给同一方法的真实证据；每条独立可理解。品牌是捷境，当前支持eBay，不包装为全平台自动赚钱工具。

采用现有v10纸白/森林绿/淡青柠视觉作为样片起点：背景 `#F6F7F2`、主文 `#182823`、强调 `#D7EE9A`、结构线 `#315E50`、次文 `#52655B`。复用 `hyperframes/commerce-v10/DESIGN.md`，不改全站品牌。中文宋体标题与黑体说明先核对字体可用性和许可；没有对应字体不静默降级成错字/方框。

竖屏1080×1920、30fps。画面一主两辅：一个经营对象占视觉中心，辅助文字解释动作，背景仅提供空间；不要同时用大量数据卡/粒子/高亮吸走注意力。真实界面短镜头只作证据，正式录制时脱敏并核实当前功能。不伪造捷境UI、订单或发布成功。

字体建议从标题84–112px、正文/字幕36–48px起排，再按手机预览校正；这些是设计起点，不是平台规范。字幕不超过两行为起点，顶部/底部/右侧UI遮挡区按实际发布预览检查，安全区不能只靠固定数字。画面标题不逐字重复整段旁白，观众静音也能理解关键动作。

音乐只用权利清楚的已有素材或原创；无合适授权音乐时宁可先用干净旁白和必要原创音效。禁止复用原左右声道300ms错位配方。所有新输出进D盘全新期号/版本目录，不覆盖旧影片，也不把已提交v10剪短冒充新一期。

## 01期 / 中午12:00 / AI电商实用课

**问题**：重复工作很多，AI先帮哪三件？

**本条价值**：把上架准备拆成“资料、文案、图片需求”，让观众判断自己卡在哪一段。目标约35–40秒，按试读和画面阅读速度调整，不硬凑。

封面草案：`AI先接手 / 哪3件事？`；侧边小字“电商上架准备”。不以大Logo开场。

旁白草案（数字指标、已发布/已成交等不写入）：

> 做电商，先让AI接手哪三件重复工作？从上架准备开始。第一，把散落的商品资料整理清楚：材质、尺寸、发货信息，都留好来源。第二，起草英文标题和卖点，再核对商品事实。第三，梳理主图、规格图和场景图分别要讲什么。资料、文案、图片需求接起来，重要决定由你确认。捷境当前支持eBay。你最想先处理哪一步？

### 七镜文字分镜

| 时间起点 | 主画面与层次 | 运动/剪辑与信息任务 |
|---|---|---|
| 0–3秒 | 大标题在左上，右下三组真实工作材料局部：资料、文案、图片需求；不出现无关产品大特写 | 0.3秒内问题标题已可读，三组材料随后依次进入并形成层次；第一眼识别“电商准备”，不播Logo片头 |
| 3–8秒 | 资料局部被放大，来源标记与一个属性对应；其余材料退到侧边 | 顺着动作切入，将散乱信息聚拢；不把三张卡平移一遍当全部动画 |
| 8–13秒 | 一份资料形成清楚的字段结构；未核实处留待核对标记 | 只强调一次“信息有来源”，暂停给观众读；不展示私人地址、账号或虚构属性 |
| 13–20秒 | 中文事实与英文草稿左右有明显主次；保留一个具体修改点 | 文本由事实映射成草稿、再编辑；草稿标签可见，不用无证据“已上架”绿勾 |
| 20–27秒 | 三种图片需求占前中后景，主图先清楚，再露出规格/场景 | 用同一素材框变换角色，说明每张图回答的问题；商品外形不被生成式美化篡改 |
| 27–33秒 | 三段工作收束成可理解的一条准备路径，确认节点最突出 | 前面真实出现过的对象按因果连接；不是突然叠一页全功能清单 |
| 33–40秒 | 保留一个主体与一句提问，捷境署名及“当前支持eBay”轻量呈现 | 节奏放缓给观众读完，结尾只问“你最想先处理哪一步？”；不要同时催赞/关注/私信 |

实际旁白配音后按语义重新对齐时间；以上不是已录音时间码。

## 02期 / 晚上20:00 / AI电商工作流实操

**问题**：真实商品资料怎样变成可核对的eBay上架草稿？

**本条价值**：展示来源 → 草稿 → 人工核对的实际过程，建立信任。目标约45–55秒，以可读性为准。缺真实操作证据时先保留分镜，不能生成一个仿UI成功动画代替实操。

封面草案：`真实商品资料 / 怎样变成上架草稿？`；侧边小字“eBay实操”。

旁白草案：

> 一份真实商品资料，怎么变成eBay上架草稿？先保留原图和参数来源，把材质、尺寸、颜色、发货信息分开。信息对不上，先标出来，不让AI猜。再根据核对后的资料起草英文标题、卖点和详情，同时整理每张商品图要说明什么。接着回到草稿里修改，检查内容与来源是否一致。这条演示停在草稿核对，不触发真实发布。捷境当前支持eBay，重要操作由你确认。你最想看哪一步展开？

### 七镜文字分镜

| 时间起点 | 画面证据与构图 | 运动/声音与准确性 |
|---|---|---|
| 0–4秒 | 左侧可核验商品资料局部，右侧真实草稿局部，中间留白提出问题 | 先看得见输入/输出，不承诺“几秒必出单”；必要局部裁切，不把浏览器整屏缩到看不清 |
| 4–11秒 | 原资料形成来源索引，当前核对字段占主要位置 | 相同元素连续运动连接两镜；只显示与本条有关的商品资料，不含客户信息 |
| 11–18秒 | 一个真实冲突被标出，来源并排，未确定值留空 | 用有意义的短停顿讲清“不能猜”；无真实冲突案例则改为核对过程，不人为造错 |
| 18–27秒 | 已核对事实对应英文标题/卖点草稿，保留少量真实界面 | 让观众看见编辑步骤；录屏/截图须有来源日期和能力依据，不沿用过期假数据 |
| 27–35秒 | 图片任务说明与同一商品对应，规格/场景用途清楚 | 图文角色变化是这镜主动作；不改产品材质、颜色、开孔结构或包装事实 |
| 35–44秒 | 真实草稿修改点前后对照，以一个可读的局部为主 | 以光标/焦点指引视线，不用遍地发光线；旁白与实际修改同步 |
| 44–55秒 | “草稿核对”状态留下，当前eBay与确认节点清楚；单一提问 | 不展示发布成功、虚构收入或点击真实发布；结尾给阅读时间 |

商品候选是经营者已授权的地漏过滤垫资料，但原文件必须在制作端实际可读并与来源匹配。标题“硅胶”和参数“PVC”、商品图11.5×11.5cm与尺寸重量栏20×20×0.5cm存在口径差异；不能自行断言后者一定是包装尺寸，不把未解决的具体值说成已核实。首条实操可只展示如何标出差异，成片中不承诺防臭、防虫或绝不侵权。

说明：从资料来源，到英文草稿，再到逐项核对。本期展示上架准备，不触发真实发布。你最想看哪一步展开？
候选话题：#跨境电商 #电商运营 #AI工具 #eBay运营

## 第一个13秒样片的制作任务

从01期0–13秒先做，固定13秒、30fps、390帧，不先渲染全部14条。候选视觉方向已在既有七天方案比较，本次以纸质编辑台和真实材料编排为执行起点；仍需高保真画面和有声样片审看，不把此前v10的部分认可当本样片通过。

1. 先输出0.8、2.5、5.0、8.0、10.5、12.0秒对应的六张高保真静态帧。要求不同画面职责，不是同一卡片六种进场。
2. 首3秒“杂乱的三件重复工作 → 明确的问题”；3–8秒“资料被归纳”；8–13秒“来源与字段连上”。同一对象贯穿，尽量靠连续动作而非全屏擦除转场。
3. 加与这段内容一致的自然中文旁白，使用一条全局旁白母轨，镜头不切断句子、不靠变速凑时长，逐段听审；先解决正确声道和可理解性，再配必要音效。不复用内容不匹配的旧旁白，不伪称已生成新音色。
4. 以1倍速和手机尺寸看完整样片，核对字距、层次、动作停顿、同步、重音/重叠、关键字是否被平台UI遮挡。技术与审美分别出回执。
5. 不合格先修样片，不扩展完整片。通过后才按同一视觉语法扩成两条，并各自独立质检。

## 第一轮实验与后续动作

首轮主要实验变量是“具体经营问题开场”，保持时段和视觉基本一致；不同时频繁换时长、标签和封面。24/72小时用同龄汇总数据比较，先看受众是否相关、内容是否看得明白，再看可核验咨询与体验。两条题材/时长不同，不能把它们直接当随机A/B因果实验。
