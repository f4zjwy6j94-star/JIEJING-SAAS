# 捷境讲解片 v3：先把话讲明白，再设计画面

2026-10-07，北京时间。经营者已否决v2的声音、叙事、卡片堆叠和配色，并认为第一版视觉更好。v2的技术导出通过不等于创意通过，不再标作待直接采用成片。保留原文件；修订沿用现有工程。

## 这次实际修正

上一版的问题是先有12张场景卡，再为每张写一句话；旁白被逐句合成，停顿规律、解释割裂。登录和菜单过早占据篇幅，没回答卖家为什么需要捷境。新的组织顺序是：卖家的处境→具体阻力→捷境怎样分担→商家怎样配合→结果和决定权。先把整段讲述写通，静音画面再承担举例与解释。

采用第一版更明确的蓝色/黑白层次，去掉v2绿金宋体方案。首段用同一件立体商品和多个工具窗口连续运动、汇合到同一个工作台；没有逐张截屏切换，没有图表假数据或成功状态。原有网页登录页不进入开篇。

当前只制作16秒开篇方向样片及两种声音试听，用于确认修正是否有效，不称完整新版。声音为Microsoft Edge公开朗读服务的合成音色，不仿冒真人。使用现有网络和代理、无账号付费/密钥；仅发送新写的非敏感讲解文字，未发送历史、图片或客户资料。服务可生成不代表听感已通过；主人可否决两种音色。

## 完整白话讲稿（新版提案，尚未制作全片）

你有货，也有eBay店。可上一个新品，要查市场、写英文，还要准备图片。事情，全压在自己身上。

捷境做的，就是把这些准备工作，放进同一个工作台。

你可以用中文告诉它：“我有一款咖啡量勺，想放到店里卖，先帮我看看怎么做。”再把真实照片和商品资料交进来。

它能帮你做市场调研，准备英文商品页和素材。缺资料，就先补；内容不合适，就接着改。你不用每换一个环节，又把这件商品从头解释一遍。

准备好后，在捷境里检查发布条件。你确认，再通过eBay接口发布到已连接的店铺。客服、订单和经营复盘，也能接着协助。

简单说，你给目标和真实资料，捷境帮你把事情往前做；关键决定，还是你来定。

想试试，就到捷境官网，从一件商品、一个具体任务开始。目前先支持eBay。

这是能力介绍，不保证每个账号可刊登、自动成功、节省固定时长或获得收入。正常发布继续走捷境接口，不导向手填eBay后台。后续平台不可声称已接入。

## 声音与画面的因果对应

| 讲解作用 | 声音内容 | 画面如何帮助理解 |
| --- | --- | --- |
| 让目标商家认出自己 | 有货、有店，准备新品仍有多件事 | 同一件立体商品始终在场，调研/英文/图片工具围绕它出现，呈现重复切换的负担。 |
| 一句话说清用途 | 捷境把准备工作放进一个工作台 | 已出现的工具沿连续路径归位到同一个工作区；不是切到一张功能列表。 |
| 给商家一个可照做的起点 | 用中文说目标，再给真实资料 | 后续全片使用真实录制的目标输入、上传/资料校验动作。不得伪造模型输出或刊登成功。 |
| 讲清商家和系统的分工 | 系统准备，商家补资料和修改 | 保留同一商品上下文，用实际草稿修改表现改动如何回到任务；原图仅在必要时展示。 |
| 说明怎样走到店铺 | 预检，商家确认，经接口发布 | 工作原理动画明确区分准备/确认/执行；只有另有真实授权证据才用真实发布结果。 |
| 留下用途和一个行动 | 从一件商品、一个任务开始 | 简洁品牌收束、官网入口；不在结尾塞满套餐和所有菜单。 |

完整片不以固定秒数牺牲解释；先按正常说话速度配音，再决定总时长与镜头。全片真实界面镜头预计约20%，须按解释需要决定，不能拿比例代替实际审看。
