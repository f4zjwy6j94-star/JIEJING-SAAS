# 免费配音选择核查（2026-10-07，北京时间）

经营者最新要求：仍偏好更自然AI音色；上轮MiniMax可在无更好选择时作为备选，具体男女声未指定；只用免费方案。此前USD1付费试音提议撤销。不存在免费额度、商用权或调用入口的证据时，不能说已经免费打通。声音合格与模型许可、当前算力、托管服务价格分开判断。

| 方案 | 本轮官方事实 | 当前可用程度 |
| --- | --- | --- |
| MiniMax speech-2.8-hd | API USD100/百万字符；公开音色试听不等于免费定制 | 无本人账户/授权；免费积分、下载及推广权未核实，不调用收费API |

| CosyVoice3 | GitHub代码LICENSE与2512模型卡均为Apache2.0 | 没有模型授权费；新运行依赖/算力和授权音源未验证，不等于免费托管服务或更好声音 |
| 既有Kokoro | 模型Apache2.0；现有隔离工具已在此前成功合成 | 无需另购配音服务即可复用，但之前的听感不足，不能称已解决 |

- cosyvoice3-conversation-official.wav：4.8秒。

这些是公开演示，仅供私人听感对比；不直接剪入宣传片，不据模型许可证推导具体演员/参考声线的商用或克隆授权。本助手无可用听觉输入，没有冒称亲耳评定自然度。没有请求生成、上传声音、克隆真人、登录、付费或下载模型/安装依赖。

下一步只在现有/经授权的零增量费用路径验证自有短稿，核对音源使用权、完整文字、自然节奏和主人听感后才替换全片。当前未完成CosyVoice自定义生成，没有新完整影片。读取示例的两次本地前缀断言失败exit1是官方仓库迁移导致，保留诊断，未扩大权限；正式读取/音频解码exit0。MiniMax猜测的网页pricing地址404、terms地址转首页均不是有效条款证据，未据此声称免费。
