# 捷境抖音推广与视频讨论 v1

2026-10-06。状态：讨论提案；经营者已选择“原创动态广告＋少量真实操作”的总体风格，具体选题、分镜、制作和发布尚未批准。经营者本轮明确开始讨论“怎么推广、抖音视频怎么做”，允许本轮策略和内容构思；此前资料对齐阶段的暂停要求仍约束实际制作和发布。

## 已确定的起点

捷境约定的公开收费首版软件已交付8/8，后续工作转向推广与获客。内部交付百分比不放进广告。正式品牌为捷境，跨境电商AI CEO SaaS，当前第一支持平台eBay。首批面向已有eBay店铺的中国卖家，沿用“捷境AI电商SAAS”账号51406410196，不重注册或擅自改名。

这轮只讨论。没有登录抖音、审看现有公开视频、核查最新后台指标或挂链资格，没有制作/渲染新素材，没有发布、私信、充值或投流。旧账号数据仅为历史快照。原三项云端测试失败、资料迁移缺项分别保留，不扩大为重新开发产品。

## 推荐的推广主线

先让目标卖家看见一个熟悉的问题，再让他看清捷境如何协助处理、具体得到什么结果，最后提供一个了解/体验入口。第一批可规划三条自然内容，先验证第一条的表达与画面，方向确定后再展开；不是现在连续生产三条，也没有承诺播放量、获客量或付费结果。

| 内容提案 | 卖家看到的价值 | 可展示的证据与边界 |
|---|---|---|
| 图片、规格都有了，为什么上架还卡着？ | 把散乱资料整理成可核对的Listing，缺失项明确待补 | 商品事实→标题/属性/描述及待确认项；不猜材质、不编效果 |
| AI写完一段英文，离上架还差什么？ | 看懂资料、Listing、素材、预检、确认和受控发布如何衔接 | 只展示核实过的功能；没有当次真实回执就不演“eBay发布成功” |
| 买家连着问尺寸和到货时间，怎样整理回复？ | 把买家问题理清，给出有依据的回复建议，需要商家决定的事项停在确认 | 若使用情境示例明确标注；不伪造真实客户聊天、退款或订单 |

推荐第一条从“图片和规格到可核对Listing”切入。它有清楚的输入与输出，观众容易判断是否与自己相关。后续通过流程与客服内容逐步说明AI CEO的经营协助范围，不把品牌缩成只写文案的工具。

## 画面形式候选

1. **原创动态广告＋少量真实操作（已获经营者选择）**：商品资料、规格、字段之间有可理解的运动与转化，手机上一眼看清主信息；短真实产品镜头证明输出存在。自然中文旁白配字幕，第一轮不要求经营者出镜。重点是“看懂发生了什么”，不靠无关的科技粒子堆效果。
2. **真实使用演示＋清楚讲解（保留备选）**：更直接展示关键操作和结果，便于解释细节；需要控制镜头停留、小字和界面信息密度。适合后续回答具体使用问题。

风格选择来自经营者对本轮可选问题的明确答复；该问题已说明选择不代表制作或发布授权。上述仍不是已经制作的高保真概念。此前A/B/C方向、六帧和12秒样片保留，未获批准，不默认它们就是新方向。已否决37.5秒旧片不复用；不重复长时间裁切同一网页、文字多层争抢注意的问题。

## 第一条的内容节奏草案

建议完整片约25–35秒，时长随可读性调整，没有“几秒完成上架”的效率承诺。

| 段落 | 观众需要理解的内容 | 画面意图 |
|---|---|---|
| 开头约0–3秒 | “图片、参数都有了，怎么还没整理好一条Listing？” | 直接看到分散的图、规格与空缺字段，开头即辨认卖家场景 |
| 中段约3–10秒 | 材料分散、字段缺口让上架准备反复中断 | 一次突出一个问题，避免字幕解释另一件事 |
| 中段约10–24秒 | 捷境把信息整理为可核对的内容，缺口保留待补/确认 | 原创动态表达配短真实结果镜头；示意画面不伪装成真实UI或平台回执 |
| 结尾约24–35秒 | “捷境，跨境电商AI经营工作台，目前支持eBay。”＋一个了解入口 | 品牌与清楚的下一步，不在一条视频堆所有模块或套餐 |

这只是内容讨论，不是定稿配音、完整分镜或制作授权。真实演示内容和素材权利在具体镜头选定时核验；历史测试图片不自动转为新宣传批准。材质“硅胶/PVC”冲突保持待核，不用未证实的商品功效吸引观众。

## 观看之后如何承接

观众看视频→进入账号主页了解→通过账号实际允许的咨询/体验入口→注册捷境→完成一个有实际价值的首任务→观察付费与留存。

账号官网组件资格和当前发布规则仍需在准备发布时实查，不能把旧Windows登录态当成云端已登录。每条只设一个行动入口，不虚构“领取资料/优惠”，不恢复已经退出的“私信内测”口径。暂以自然内容方案讨论；如需DOU+等付费推广，先单独明确预算、目标、时长和止损，再取得相应授权。

复盘先看合格卖家咨询、注册、首任务完成及付费/留存，再结合开头留存、完播与主页访问判断内容问题。首批三条是学习批次，不是平台算法定律。旧15秒作品的历史数据仅供线索，未审看原片前不作原因定论。

## 进入制作前

先讨论并选定主表达和风格。经营者明确开始制作后，沿用既有工程推进2–3个不同视觉概念、6–8帧高保真分镜与10–15秒风格样片；方向确认后才完整成片，公开发布另行确认。音色、版权音乐、账号入口和需付费的服务届时按实际可用条件处理，不假定本机插件或登录已迁入。
